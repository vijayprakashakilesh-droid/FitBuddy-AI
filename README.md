# FitBuddy

FitBuddy is an AI-powered fitness plan generator built with:

- FastAPI
- Python
- Gemini AI
- SQLAlchemy
- SQLite
- Jinja2
- HTML
- CSS

## Features

1. User registration
2. Personalized 7-day workout plan
3. Goal-based fitness planning
4. Low/Medium/High workout intensity
5. AI nutrition/recovery tip
6. Feedback-based plan update
7. SQLite database
8. Admin dashboard
9. REST API
10. Swagger API documentation
